# ЯКласс Помощник (Gemini)

Chrome-расширение, которое **автоматически проходит теорию и решает задания на
[yaklass.ru](https://www.yaklass.ru)** с помощью Google Gemini.

> Расширение никуда не отсылает твои данные кроме Google AI Studio (Gemini).
> API-ключ хранится **локально** в браузере (`chrome.storage`).

## Возможности

- Автоматически кликает «Прочитано» / «Далее» на теоретических шагах.
- Решает задания: текстовые ответы, выбор одного/нескольких вариантов, выпадающие списки.
- Использует Gemini 3 Flash (или другую модель по выбору) как «мозг».
- Поддерживает многомодальный режим: умеет видеть картинки в условиях
  (графики, схемы, формулы).
- Имитирует поведение человека: случайные задержки, посимвольная печать.
- Логирование в попапе, счётчик решённых задач и ошибок.

## Установка (Developer mode)

1. **Скачай / склонируй этот репозиторий** на компьютер.
2. Открой в Chrome адрес: `chrome://extensions`.
3. Включи переключатель **«Режим разработчика»** в правом верхнем углу.
4. Нажми **«Загрузить распакованное»** и выбери папку `yaklass-helper`.
5. Закрепи иконку расширения в панели (значок «🧩» рядом с адресной строкой).

## Получение Gemini API ключа (бесплатно)

1. Зайди на <https://aistudio.google.com/apikey>.
2. Нажми **«Get API key» → «Create API key»**.
3. Выбери проект (или создай новый) → скопируй ключ (`AIza...`).

> Бесплатный тариф даёт ~10–15 запросов в минуту и ~1500 запросов в день.
> На бесплатном тарифе Google может использовать твои запросы для обучения
> моделей. Если это не подходит — включи биллинг в Google Cloud.

## Использование

1. Залогинься на `yaklass.ru`, открой нужный предмет/тему/задание.
2. Нажми на иконку расширения, **введи Gemini API ключ** и нажми «Сохранить».
3. Выбери модель (по умолчанию `gemini-3-flash` — рекомендуется).
4. Выбери скорость:
   - **Медленно** — задержки 2.5–5.5 сек между действиями (безопаснее).
   - **Обычно** — 1.2–2.8 сек.
   - **Быстро** — 0.4–1.2 сек (есть риск, что платформа заметит).
5. Нажми **«▶ Запустить»** и наблюдай.
6. В любой момент можно нажать **«■ Остановить»**.

## Архитектура

```
yaklass-helper/
├── manifest.json      Manifest V3
├── background.js      Service worker: запросы в Gemini API
├── content.js         Контент-скрипт: парсит задания, кликает, печатает
├── popup.html         UI попапа
├── popup.js           Логика попапа: настройки, статус, лог
├── popup.css          Стили попапа
└── icons/             Иконки расширения
```

### Поток работы

```
Popup --START--> Content script (yaklass.ru tab)
                       │
                       ├── detectAction() — что на странице?
                       │     ├── theory → click «Прочитано»
                       │     ├── task   → handleTask()
                       │     ├── next   → click «Далее»
                       │     └── finish → click «Закончить попытку»
                       │
                       └── handleTask():
                             ├── extractQuestionText()
                             ├── extractFormElements()
                             ├── extractImages()  (опционально)
                             ├── send to background → Gemini
                             ├── applyAnswers() (печатает / кликает)
                             └── click «Проверить»
```

## Известные ограничения

- Задания с **перетаскиванием** (drag-and-drop) и сложные **интерактивные**
  виджеты пока не поддерживаются.
- Точность ответа зависит от модели. Gemini 3 Flash хорош, но иногда
  ошибается, особенно в задачах с длинными формулами или нестандартной
  логикой.
- Расширение может «зависнуть», если ЯКласс показал диалог/попап, не
  предусмотренный логикой. В этом случае останови и перезапусти.
- Платформа может детектировать слишком быстрые ответы. Используй режим
  «Медленно» при подозрениях.

## Что-то не так?

- **«Сначала введи Gemini API ключ»** — заполни ключ в попапе и сохрани.
- **«Контент-скрипт не загружен»** — обнови страницу `yaklass.ru` (`F5`).
- **HTTP 429 от Gemini** — превышен лимит запросов. Подожди минуту или
  переключись на `gemini-3.1-flash-lite`.
- **HTTP 400 / model not found** — модель недоступна. Попробуй другую.
